# Sobre o Projeto

O **Uso de Redes Neurais Artificiais no Controle Inteligente de Tráfego** é um projeto acadêmico voltado ao estudo da aplicação de técnicas de Inteligência Artificial na gestão do trânsito urbano.

A proposta consiste em analisar como Redes Neurais Artificiais podem auxiliar na tomada de decisões relacionadas ao controle semafórico, fluxo de veículos e otimização da mobilidade, utilizando conceitos presentes em Sistemas Inteligentes de Transporte (ITS).

---

# Objetivos

- Estudar os fundamentos das Redes Neurais Artificiais.
- Compreender aplicações de Inteligência Artificial no controle de tráfego.
- Pesquisar soluções para redução de congestionamentos urbanos.
- Analisar o funcionamento de Sistemas Inteligentes de Transporte (ITS).
- Relacionar conceitos de aprendizado de máquina com problemas reais de mobilidade urbana.

---
